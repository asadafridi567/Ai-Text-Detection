A full-stack **SaaS web application** that detects AI-generated text, checks for plagiarism, and humanizes AI content — built with a microservices-inspired architecture using React, Django, Flask, and Celery, fully containerized with Docker.

</div>

---

## ✨ Features

- 🔍 **AI Text Detection** — Identify whether content was written by a human or generated by AI
- 📄 **Plagiarism Checker** — Scan and compare text for originality
- ✍️ **Text Humanizer** — Rewrite AI-generated content to sound more natural
- 🔐 **User Authentication** — Secure login with email verification and Google OAuth
- ⚙️ **Async Task Processing** — Background jobs handled via Celery and Redis
- 🐳 **Fully Dockerized** — One-command setup with Docker Compose
- 🚀 **CI/CD Pipeline** — Automated testing and deployment with GitHub Actions

## 🚀 Getting Started

### Prerequisites
- [Docker](https://docs.docker.com/get-docker/) & Docker Compose installed
- [Git](https://git-scm.com/)

### 1. Clone the repository
```bash
git clone https://github.com/asadafridi567/Ai-Text-Detection.git
cd Ai-Text-Detection
```

### 2. Set up environment variables
Create a `.env` file in the root directory:
```env
# Django
SECRET_KEY=your_django_secret_key
DEBUG=True

# Database
POSTGRES_DB=aitextdb
POSTGRES_USER=postgres
POSTGRES_PASSWORD=your_password
DATABASE_URL=postgresql://postgres:your_password@db:5432/aitextdb

# Redis
REDIS_URL=redis://redis:6379/0

# Google OAuth
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret

# Email
EMAIL_HOST_USER=your_email@gmail.com
EMAIL_HOST_PASSWORD=your_app_password
```

### 3. Run with Docker Compose
```bash
docker-compose up --build
```

### 4. Access the app
| Service | URL |
|---|---|
| Frontend | http://localhost:3000 |
| Django API | http://localhost:8000 |
| Flask AI Service | http://localhost:5000 |

## 🔑 Key Implementation Details

### Authentication Flow
- Users register with email and receive a **verification email** before gaining access
- **Google OAuth** login supported for quick sign-in
- JWT-based session management via Django REST Framework

### Async Processing with Celery
- Heavy AI inference tasks are offloaded to **Celery workers** to keep the API responsive
- **Redis** acts as the message broker between Django and Celery workers

### AI Detection Models
- Model training and experimentation done in **Jupyter Notebooks** inside the `AI/` folder
- Flask serves the trained models as a lightweight microservice consumed by Django

### CI/CD with GitHub Actions
- On every push to `main`, automated tests run and Docker images are built and validated
